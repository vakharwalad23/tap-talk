**Local speech-to-text for macOS. Press a key, speak, paste. Nothing leaves your device.**

TapTalk is a fully local, privacy-first dictation app for macOS. It runs Whisper inference directly on your Mac — no cloud APIs, no network requests, no telemetry. Hold a hotkey, speak, and your words are transcribed and pasted into whatever app you're using.

Built with SwiftUI and Rust, TapTalk leverages Apple's Neural Engine through Core ML for hardware-accelerated inference while keeping the core transcription engine portable and dependency-free.

## Why TapTalk?

Most dictation tools send your audio to a server. TapTalk doesn't. Every byte of audio stays on your machine, processed in real-time by a local Whisper model. There's no account to create, no API key to manage, and no recurring cost.

It's also fast. On Apple Silicon, even the largest Whisper model runs with low latency thanks to Core ML acceleration. For quick notes, the Tiny model transcribes nearly instantly.

## Features

- **Four model tiers** — Tiny, Base, Small, and Large v3. Trade speed for accuracy depending on your needs.
- **Multilingual** — English plus 13 Indian languages including Hindi, Tamil, Telugu, Kannada, and more.
- **Neural Engine acceleration** — Core ML integration for hardware-accelerated inference on Apple Silicon.
- **Global push-to-talk** — A system-wide hotkey that works from any application.
- **Auto-paste** — Transcribed text is automatically inserted into the focused text field.
- **Word dictionary** — Custom replacement rules organized by category (technical jargon, proper nouns, shorthand) applied as post-processing.
- **Smart rewriting** — Optional LLM-powered post-processing to clean up grammar and formatting.
- **Fully native** — SwiftUI and Rust. No Electron, no WebView, no web tech.

## Requirements

- macOS 14 or later
- Apple Silicon (M1, M2, M3, or M4)
- Xcode 15 or later
- Rust 1.77 or later
- [xcodegen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`)

## Getting Started

```bash
git clone https://github.com/AiSaraS/tap-talk.git
cd tap-talk
make run
```

This single command compiles the Rust core, generates Swift bindings via UniFFI, builds the Xcode project, and launches the app. Models are downloaded on first use to `~/Library/Application Support/talk.tap.app/models/`.

### Build Targets

| Command | Description |
|---------|-------------|
| `make run` | Full build and launch |
| `make build` | Build without launching |
| `make rust` | Rebuild Rust core only |
| `make bindings` | Regenerate Swift bindings |
| `make release` | Optimized release build |
| `make clean` | Remove all build artifacts |

## How It Works

TapTalk is split into two layers. The **Rust core** handles audio capture (via cpal), voice activity detection (Silero VAD), and Whisper inference. The **SwiftUI app** provides the interface, hotkey management, accessibility integration, and system services. The two communicate through a thin FFI bridge generated by [UniFFI](https://mozilla.github.io/uniffi-rs/).

When you press the hotkey, TapTalk begins capturing audio from your default input device. Silero VAD detects when you start and stop speaking. Once you release the key, the recorded audio is sent to whisper.cpp for transcription. The result passes through your custom dictionary replacements and optional LLM rewriting before being pasted into the active text field via the accessibility API.
