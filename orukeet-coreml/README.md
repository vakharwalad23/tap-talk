# orukeet-coreml

Convert the Orukeet ASR model to the Core ML bundle that the FluidAudio Swift SDK loads onto the
Apple Neural Engine, and benchmark it head to head against NVIDIA Parakeet TDT 0.6B v3 on FLEURS.

Orukeet is a Parakeet TDT 0.6B v3 fine-tune with frozen Gabor kernels (arXiv 2609.10054). It keeps
Parakeet's architecture, decoder, and tokenizer, so at the Core ML graph level the conversion is a
weights swap. It covers the same 25 European languages (no Hindi, no Devanagari). Everything here is
offline build and evaluation tooling; nothing is imported by the app.

## What it does

`make bench` builds the Orukeet Core ML bundle, stages both models, transcribes FLEURS through
FluidAudio, and writes WER and CER reports to `reports/` (generated locally, not committed).

## Upstream conversion and parity benchmark

The Orukeet Core ML build TapTalk ships comes from the model author. Nathan Roll (Oruk, creator of
Orukeet) produced an official Core ML export and a head-to-head Orukeet vs Parakeet parity
benchmark, with faster greedy decoding, in
[Oruk-AI/orukeet#6](https://github.com/Oruk-AI/orukeet/pull/6). This directory is TapTalk's own
earlier conversion and FLEURS evaluation tooling.

## Quickstart

Apple Silicon Mac, with `uv`, Xcode command line tools, and `git`.

```bash
make preflight            # check the machine and dependencies
make setup convert quantize   # produce the float32 and int8 Core ML bundles in out/
make data                 # download FLEURS (about 11 GB)
make bench                # build, stage models, run passes, score reports
```

`make help` lists every target. Full run guide: [docs/RUNNING.md](docs/RUNNING.md).

## Layout

```
Makefile              every entry point
scripts/
  lib/                common paths and preflight (Silicon and dependency detection)
  convert/            NeMo checkpoint to Core ML bundle
  quantize/           int8 encoder bundle
  bench/              FLEURS prep, Swift harness driver, WER and CER scoring
  publish/            Hugging Face push, CC-BY-SA-4.0 license, model card
swift/                Swift benchmark harness (FluidAudio)
docs/                 RUNNING, BENCHMARKS, ANALYSIS
reports/              benchmark results (generated by make bench, gitignored)
```

Working directories are created by the targets and are gitignored: `vendor/` (converter), `out/`
(bundles), `models/` (staged), `data/` (FLEURS), `work/`, `swift/.build/`, `reports/_raw/`.
